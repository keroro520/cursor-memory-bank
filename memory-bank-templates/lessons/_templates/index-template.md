## 📖 Usage Guide

### Finding Relevant Lessons

1. **By Module**: Browse the module categories above to find lessons for specific areas
2. **By Tag**: Use tags to find cross-cutting concerns (performance, security, etc.)
3. **Search**: Use your editor's search (Ctrl/Cmd+F) to find keywords

### Adding New Lessons

Lessons are automatically extracted during the `/archive` command:
- The system analyzes reflection documents
- Identifies actionable, reusable insights
- Organizes them by module
- Updates this index

### Lesson Quality Standards

Each lesson should be:
- ✅ **Concise**: Context ≤ 2 sentences, 3-5 bullet points
- ✅ **Actionable**: Provides specific guidance for future work
- ✅ **Reusable**: Applies to future tasks in the same module
- ✅ **Clear**: Uses specific language with concrete examples
